# Data Science Portfolio 2026

Welcome to my portfolio! This repository contains three core projects that demonstrate my ability to solve business problems using end-to-end machine learning pipelines.

## 🛠 Projects Overview

### 1. Bengaluru House Price Prediction (Regression)
* **Objective:** Predict property prices based on location, area, and amenities.
* **Key Skills:** Data cleaning, outlier handling, feature engineering, and Linear Regression.
* **Business Value:** Automates market-based price estimations.

### 2. Titanic Survival Analysis (Classification)
* **Objective:** Predict passenger survival based on demographic traits.
* **Key Skills:** Data imputation, categorical encoding, and Random Forest Classifier implementation.
* **Business Value:** Demonstrates the ability to classify outcomes and evaluate model performance via Confusion Matrices.

### 3. Movie Sentiment Analysis (NLP)
* **Objective:** Determine customer sentiment from text reviews.
* **Key Skills:** Text vectorization (TF-IDF/CountVectorizer), stop-word removal, and Logistic Regression.
* **Business Value:** Automates customer feedback analysis for e-commerce platforms.

## 🎓 Technical Toolkit
* **Languages:** Python
* **Libraries:** `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`
* **Workflow:** Data Exploration → Preprocessing → Modeling → Visualization → Evaluation

The project notebooks are located in the uploaded ZIP file. You can download and run these in Google Colab or Jupyter Notebook to see the step-by-step analysis.
